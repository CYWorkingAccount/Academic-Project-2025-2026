### Liste des Projets

#### Projet 1 - Application d'Optimisation d'Itinéraires (Java / POO)
Ce projet consiste à concevoir une application Java d'optimisation d'itinéraires multimodaux (train, bus, avion). Elle permet de calculer, filtrer et comparer des voyages selon leur empreinte carbone ($\text{CO}_2$), leur durée et leur prix, afin d'identifier le trajet au plus faible impact environnemental.

#### Projet 2 - Analyse et Gestion de Données Parcoursup (SQL & Shell)
Ce projet commence par l'exploration d'un jeu de données Parcoursup en lignes de commande Shell. Les données brutes sont ensuite nettoyées et intégrées dans une base PostgreSQL. Un schéma relationnel normalisé (MCD) a permis de réduire le volume de 16 Mo à moins de 6 Mo, tandis que l'ajout d'index SQL a optimisé les temps de réponse. Le projet inclut également des requêtes avancées pour recalculer divers indicateurs statistiques.

#### Projet 3 - Environnement de Développement et Forge Logicielle (Linux / Git / Pandoc)
Ce projet documente la mise en place d'une machine virtuelle Debian configurée par script. Il aborde la rédaction en Markdown et la conversion multi-format (HTML, PDF) avec Pandoc. La gestion de versions et le travail collaboratif y sont détaillés via Git, SSH et GitLab, accompagnés du déploiement local d'une forge logicielle Forgejo.

### Project List

#### Project 1 - Route Optimization Application (Java / OOP)
This project involves developing a Java application for multimodal route optimization (train, bus, flight). It allows users to calculate, filter, and compare trips based on their carbon footprint ($\text{CO}_2$), travel time, and cost, to find the route with the lowest environmental impact.

#### Project 2 - Parcoursup Data Analysis & Management (SQL & Shell)
This project begins with hands-on exploration of a Parcoursup dataset using Shell commands. The raw data is cleaned and ingested into PostgreSQL. Restructuring the data into a normalized relational schema (MCD) reduced storage size from 16 MB to under 6 MB, while SQL indexing improved query speed. The project also covers complex SQL queries to recalculate key statistical metrics.

#### Project 3 - Development Environment & Git Forge (Linux / Git / Pandoc)
This project documents the setup of a Debian virtual machine configured via script. It covers document authoring in Markdown and multi-format conversion (HTML, PDF) using Pandoc. Version control and collaboration are detailed using Git, SSH, and GitLab, along with the local deployment of a Forgejo git forge.
